# Paperang P1 打印协议规格（A5）

> **非官方互操作文档。** 本项目与 Paperang / 喵喵机 / 作业帮无任何关联，
> "Paperang"、"喵喵机"仅为设备指代。本文档由对自有设备的通信观测整理而来，
> 用于与自有设备互操作；不包含、也不涉及破解任何加密或访问控制。
> 实现以本仓库 `paperang_p1/protocol_a5.py`、`paperang_p1/device_a5.py`
> 及 `tests/test_a5.py` 的真实抓包向量为权威。

## 1. 适用范围与通道拓扑

已在 P1（固件 A5 01.03.18）上验证的正式通道：

| 通道 | 端点 | 说明 |
|---|---|---|
| USB | VID `0x4348` / PID `0x5584`，Windows 走系统 `usbprint.sys` 双向接口 | 免 Zadig，A5 帧直接读写 |
| 经典蓝牙 | RFCOMM 通道 1（SDP `00001101-0000-1000-8000-00805F9B34FB`） | 与手机 App 数据会话同通道 |

- BLE（服务 `FF00`，写 `FF02`、通知 `FF01`/`FF03`）在这台固件上仅承担
  配对/唤醒辅助角色；`FF03` 对任意写入只回 `01 01`（链路层回执）。
  本项目保留 BLE 传输实验入口，未作为正式支持通道。
- 本固件在 USB / RFCOMM 通道对协议查询与打印**没有加密鉴权要求**；
  官方 App 的加密通道与云端能力不在本项目范围内。

老款机型使用的 gen1/gen2 帧协议（帧头 `0x02`，含会话密钥握手）由
`paperang_p1/protocol.py` 实现，其格式已被下列公开项目充分文档化，
本文不再重复：

- tinyprinter / python-paperang、ihciah（gen1）
- sharperang（gen1，跨平台）
- createskyblue/paperang-miaomiaoji-tool-gen2（gen2，standardKey=0）

## 2. A5 帧格式（线上字节序）

```
A5 01 | len(LE16) | payload | crc32(payload, seed=0x35769521)(LE32) | 5A
```

- `len` 为 payload 长度；整帧总长 = len + 9。
- CRC 为 zlib 系 CRC32，固定种子 `0x35769521`（与 gen1 标准密钥相同），小端。
- payload 结构：

```
command(BE16) | msgType(1B) | contentLen(LE16) | content
```

- `command` 高字节为命令族（parent），低字节为子命令（child），如 `0x0115`。
- `msgType`：`0x01` 请求，`0x02` 响应。**它不是事务计数器**——同一时刻
  只允许一个在途命令，迟到响应无法与新请求区分，见 §5 会话约束。
- `contentLen` 必须等于 len − 5，解析端做三重校验（CRC、类型、命令匹配）。

流式解析规则：同步字节错误时按单字节滑动丢弃重新对齐；长度/CRC/内长
不合法的帧同样滑窗重试并计入坏帧统计。

响应帧 content 为 TLV：

```
key(1B) | valueLen(LE16) | value
```

查询类命令要求 TLV 中含 key `1`（返回值）；设置类命令要求 key `1` 的值
为 `00` 或空（ACK）。

## 3. USB 前导

USB 通道连接后、首个查询前需写入 10 字节前导并短暂等待（250ms）：

```
badcfe00c00300000a00
```

蓝牙通道无需前导。

## 4. 命令表（P1 / A5 01.03.18 实测）

| 命令 | 语义 | content / 返回 |
|---|---|---|
| `0x0115` | 协议版本 | 返回 ASCII，如 `01.03.18` |
| `0x0102` | 序列号 SN | 返回 ASCII |
| `0x0114` | 最大包长 | 返回 LE16（实测 1024；决定位图分块上限） |
| `0x010B` | 电量 | 返回 LE16，百分比 = 原始值 / 10 |
| `0x0109` | 自动关机时间 | 返回 LE16 秒 |
| `0x010A` | 设置自动关机时间 | content=LE16 秒；0 表示不自动关机，设置后应回读确认 |
| `0x0502` | 支持纸宽 | 返回 TLV{1: LE16 毫米}，实测 57 |
| `0x0504` | DPI | 返回 LE16，实测 200 |
| `0x050C` | 上盖状态 | `01` 闭合 |
| `0x050D` | 纸张状态 | `01` 有纸 |
| `0x0517` | 自检页 | ACK |
| `0x0516` | 走纸 | content=LE16 行数 |
| `0x0511` | 设置打印浓度 | content=1 字节 0..100 |
| `0x0520` | 纸张类型 | content=`00 00` |
| `0x0519` | 打印开始 | ACK |
| `0x051B` | 位图数据块 | content 见下，多块序号递增 |
| `0x051A` | 打印结束 | ACK（耗时较长，超时放宽） |

> 上表为本实现实际使用并逐条验证的命令。设备还响应更多命令族
> （电压、软件版本、鉴权挑战等观测记录），未纳入实现故不在此承诺。
> 本固件的正式打印路径不经过任何鉴权命令。

## 5. 打印时序

```
0x0511(浓度 1B) → 0x0520(00 00) → 0x0519(开始)
  → 0x051B × N（位图分块，order=1..N） → 0x051A(结束)
  → [可选] 0x050C/0x050D 状态复查 → [可选] 0x0516 走纸
```

位图行格式：384 点宽 = 48 字节/行，MSB 在前，1=黑。
分块 content 结构（`protocol_a5.bitmap_content`）：

```
LE16(order) | LE16(innerLen) | inner
inner = 01 | LE16(48) | LE16(rowOffset) | 00 | LE16(rowBytes) | rows
```

分块大小：`min(960, ((max_length - 26) // 48) * 48)` 字节。

**关键约束（实测得到，违反会导致不出纸或会话作废）：**

1. 打印开始（0519）到位图结束（051A）之间**不得插入任何状态查询**，
   否则设备拒绝后续位图帧。
2. 命令必须串行：一个在途请求未收到匹配响应前不得发送下一个。
3. 任一命令超时即判定会话污染：必须关闭连接重建，**不得原地重试**——
   迟到的响应会被误认成新请求的应答。
4. 发送途中断连的任务结果未知（`unknown`），不能自动重打；
   未发送的任务可保留（`held`）待设备唤醒后恢复。
5. 深度休眠/已关机的设备无法由软件唤醒，需按实体键。
