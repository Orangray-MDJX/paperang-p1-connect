## 可靠性边界 *（实机验证的产品语义）

| 场景 | 行为 |
|---|---|
| 打印中拔 USB / 断蓝牙 / 设备关机 | 任务标记 unknown，禁止自动重打 |
| 缺纸 / 开盖 | 任务暂停为 held，装纸/合盖后手动恢复 |
| 发送中取消 | 分片边界停止，结果标记 unknown |
| 设备空闲 30 分钟（自动关机设 0） | 无断连，状态轮询持续 |
| 服务重启 / 电脑重启 | 队列 SQLite 持久化，历史任务不重打 |
| 登录自启 | 计划任务方式验收（真实重启） |
