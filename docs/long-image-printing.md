# 长图与原生纸张协商

## 长图上传

当前手机入口：`http://<电脑局域网IP>:8631/long-image`。与电脑连接同一可互通Wi-Fi。
选择PNG/JPEG，保持“裁去外围白边”关闭以保留原图，点击生成预览，核对首尾与预计纸长后确认打印。也可使用页面提供的12段编号测试图，预计约30厘米。

图片按384点宽等比例缩放，不适配固定页面高度。预计毫米值来自设备自报DPI，包含尾部走纸，仅供估算。限制40MB、2000万输入像素、16000输出行（约2米）；超限拒绝，无静默截断。暂不支持HEIC、多帧图片或批量打印。

预览30分钟有效。确认使用预览时的同一份黑白图；同一凭证重复确认返回同一个任务ID，包括服务重启后。页面保存最近任务凭证供刷新后查询，凭证可访问该任务，不可访问其他任务。预览存于现有SQLite队列，提交后删除预览副本，打印内容仍依队列持久保留。未提交预览过期后在后续上传时清理，缓存最多8份、64MB。

未发送的取消任务不出纸；发送中的取消在分片边界停止继续发送并关闭连接，标“结果未知”，已接收缓冲仍可能继续出纸。缺纸/开盖暂停任务仍需电脑管理页手动恢复，不向LAN开放配置、文件路径或恢复接口。

专用接口：POST `/long-image/preview?trim=false`（原始图片请求体）、GET `/long-image/preview.png`、POST `/long-image/submit`、GET `/long-image/job`、POST `/long-image/cancel`。上传及写操作要求`X-P1-Upload: 1`；除上传外凭证放`X-P1-Token`请求头，不放URL。上传响应含token、rows、length_mm、expires_in。沿用配置子网限制，无跨域许可。

## 原生打印实验

默认57×100mm；兼容逻辑页面4×6英寸与A4，最终仍按384点宽缩放。配置`ipp_long_media=true`额外提供57×200、57×300、57×500mm，默认关闭。Android Chrome和相册实测均只显示4×6、A4，忽略自定义卷纸长度；实验完成后已恢复关闭。未声称这条路径解决Android长图排版。

服务解析IPP嵌套`media-col`，验证尺寸属于当前声明集合，记录请求尺寸、格式、渲染页数及尺寸。不自动拼页、不删除页眉页脚。Android可能缓存旧能力，或完全忽略自定义长纸张；手机应用也可能在发送前缩小或裁切长图，因此不能保证扩大IPP纸张即可解决。
